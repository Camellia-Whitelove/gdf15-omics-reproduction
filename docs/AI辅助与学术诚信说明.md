# AI 辅助与学术诚信说明

课程要求：「复现过程中如使用大语言模型辅助，需在报告中明确说明使用范围与边界」。本文件即为该说明，同时写入课程复现报告（Word）与幻灯片。

## 1. 大语言模型（AI）的使用范围

本次复现中，AI 辅助参与了以下环节：

| 环节 | AI 参与程度 | 人工复核情况 |
|---|---|---|
| ENA 下载排障（传输停滞、分段超时、MD5 不一致） | 提供重试与分段策略建议 | 32/32 校验结果由脚本直接输出，已核验 |
| R / Python 脚本编写（质控、比对、计数、DESeq2、绘图、论文样式重绘） | 起草主要代码 | 每步均有脚本可重跑，关键数值经像素与源数据反向验证 |
| 论文 PDF 取色与像素比对（配色、截断轴、柱高位置） | 编写分析脚本并执行 | 结果经源数据数值反向验算（均值 3.77→y433.0、4.75→y403.6） |
| 图件样式调整（标签位置、括号、边距、叶序比对） | 迭代调试 | 每次修改后均重新生成并做像素级验证 |
| 处理记录、核查记录、复现报告撰写 | 起草与整理 | 所有数值均取自脚本实际输出，未使用论文数值替代 |
| 本 GitHub 仓库整理与 README 撰写 | 起草 | 目录与文件清单经人工核对 |

## 2. AI 未参与 / 不能声称的部分

- **实验设计与原始数据**：全部来自论文作者与公共数据库，AI 未生成任何原始或衍生数据；
- **统计结论的判定**：DEG 阈值、富集显著性、P 值等均由 R 脚本计算得出，AI 只做整理与解释，**未擅改任何统计结果**；
- **生物学解释**：报告中的生物学解读（糖/核苷酸分解代谢、快肌纤维收缩、肽/细胞因子响应等）基于 DEG 与 GO 结果归纳，需由学生本人复核后写入报告与讲解；
- **不得**：不得将 AI 生成内容当作已验证事实直接汇报；不得用 AI 虚构引用、数值或图表。

## 3. 学术诚信承诺

1. 严格区分**复现内容**（本仓库所有图与结果）与**原创观点**（差异分析、改进建议、心得体会）；
2. 报告与 PPT 中所有图表、数据均注明原始文献（DOI 10.1038/s41586-023-06249-4）与数据来源（GSE229794 / GSE229708 / PRJNA955831）；
3. 未抄袭、未买卖代码或论文报告；代码为本人小组在 AI 辅助下编写，可完整重跑；
4. 复现失败环节（Fig.4c）**如实报告**，未通过删样本或放宽阈值的方式凑出与原论文一致的结果；
5. Fig.4i 采用论文同款截断轴，已在报告与仓库中注明其视觉放大效应，并提供完整轴版本；
6. 组间讨论可共享思路，但**不直接共用代码或最终结果**。

## 4. 给汇报同学的建议

- 讲解时如实说明：哪些是原论文的结果、哪些是本次复现的结果、哪些复现失败及原因；
- 被问到 AI 使用时，按本文件第 1 节说明范围与边界；
- 生物学机制部分请自行准备，AI 的归纳不能替代对论文原文的理解。
