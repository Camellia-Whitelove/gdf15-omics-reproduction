## 2. 胫骨前肌 bulk RNA-seq（Fig.4b / 4c / 4i）

| 项目 | 内容 |
|---|---|
| GEO 系列 | GSE229794（https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE229794） |
| SRA / ENA 项目 | PRJNA955831（https://www.ebi.ac.uk/ena/browser/view/PRJNA955831） |
| 样本数 | 16（Vehicle 5、GDF15 6、Pair-fed 5） |
| 原始文件 | 32 个双端 FASTQ，每端 51 bp |
| 数据量 | 18.281 GB，295,672,731 对读段 |
| 校验 | 32/32 文件大小与 MD5 校验通过（见 `01_muscle_RNAseq/06_数据说明/download_verification.csv`） |

获取方式（脚本已入库）：

```bash
python 01_muscle_RNAseq/01_代码/上游流程/download_segmented.py   # 分段下载，支持断点续传
python 01_muscle_RNAseq/01_代码/上游流程/verify_downloads.py     # MD5 与大小校验
```

Run 列表：`01_muscle_RNAseq/06_数据说明/ena_runs.tsv`；样本与分组：`01_muscle_RNAseq/06_数据说明/sample_metadata.csv`。

### 2.1 作者提供的处理后表达矩阵

- 文件：`GSE229794_CountsNormalizedByDESeq2.csv.gz`（GEO 补充文件）
- 规模：14,538 基因 × 16 样本，数值范围 7.32–19.96
- **本次核查结论**：该表是 **DESeq2 VST 变换值**，不是原始计数、也不是 log2 计数（与本次 VST 比对 r=0.976、斜率≈0.998）。证据见 `01_muscle_RNAseq/04_结果/核查/`。
- 因体积原因未入库，可从 GEO 补充文件直接下载。

### 2.2 生理指标（Fig.2d / Fig.4i）

来自论文 Source Data（补充 Excel：MOESM4、MOESM6、MOESM11、MOESM15），属独立生理实验数据，不是 RNA-seq 矩阵。提取脚本：`01_muscle_RNAseq/01_代码/核查与重绘/extract_physiology.py`、`physiology.R`。
